1. Installation

1
Download the installer From the link provided in the email, download NutriCare-1.1.0.msi (approx. 104 MB).
2
Run the installer Double-click NutriCare-1.1.0.msi. Windows may display an "Unknown publisher" warning — click Run anyway to proceed.
3
Complete the setup wizard Follow the on-screen instructions. NutriCare will be installed to C:\Program Files\NutriCare\ and a shortcut will be added to the Start Menu and Desktop.
4
First launch Start NutriCare from the Start Menu or Desktop. On first launch you will be prompted to create an account (username and password). Your data is saved locally in %USERPROFILE%\.nutricare\ — nothing is sent to the cloud.

2. Free Trial Period (30 Days)

NutriCare includes a 30-day free trial starting from the first launch. No credit card is required.

Remaining trial days are shown in the left sidebar. When the trial expires, an activation window appears — all data entered during the trial is preserved.

Note: the trial is tied to a single machine. Installing NutriCare on a second PC starts a fresh trial on that device.

3. Purchasing and Activating a Licence

When your trial is approaching expiry (or at any time), you can purchase a permanent licence by following these steps:

1
Find your Machine ID When the activation window opens, NutriCare displays a unique Machine ID. Copy the full string (64 hexadecimal characters).
2
Send a purchase email Write to andrea.angeloni92@yahoo.it including:
  • Your chosen plan (Single / Studio / Enterprise)
  • Your Machine ID
  • Practice / company name for the invoice
3
Receive your licence key Within 24 business hours you will receive an activation key by email (a Base64 string). The key is valid only for your PC.
4
Activate NutriCare In the activation window, paste the key into the Licence key field and click Activate. The application is now permanently activated on this machine.

5. Frequently Asked Questions

What happens to my data if I don't renew?

Your data stays on your PC. NutriCare does not delete anything at expiry — you can export it or reactivate by purchasing a new licence.

Can I install NutriCare on multiple PCs?

Each licence is valid for a single machine. For multi-workstation installs (e.g. a practice with several desks) please contact us for a Studio or Enterprise quote.

How do I back up my data?

From NutriCare → Dashboard → Backup. Choose a destination folder and the application creates a compressed ZIP snapshot of the database.

Is patient data sent to the cloud?

No. All data stays on your PC in %USERPROFILE%\.nutricare\. The only internet connection is to the AI provider (OpenAI, Claude or Gemini) when using the automatic diet generation — and only with the credentials you supply.
