The parties identified above (hereinafter "Controller" and "Processor") enter into this Data Processing Agreement ("DPA") pursuant to Article 28 of Regulation (EU) 2016/679 ("GDPR"), which supplements and governs the contractual relationship concerning the supply of the NutriCare software.

Art. 1 — Subject Matter and Duration

The Processor supplies the Controller with NutriCare, a desktop application for professional nutritional patient management. This DPA governs the manner in which the Processor processes personal data on behalf of the Controller in connection with that supply.

This DPA remains in force for the duration of the NutriCare licence agreement. Confidentiality and data-deletion obligations survive termination.

Art. 2 — Nature and Purpose of Processing

Local-first architecture: NutriCare is designed with a local-first architecture. Patient data is stored exclusively on the Controller's device (%USERPROFILE%\.nutricare\) and is not transmitted to the Processor's servers. The Processor therefore does not access or process patient personal data in the ordinary course of software operation.

Processing carried out by the Processor is limited to:

  • Delivery of the software and its updates;
  • Licence management (RSA signature verification against a local machine ID — no personal data transmitted);
  • Technical support, only upon the Controller's explicit request and following voluntary transmission of anonymised logs.

Art. 4 — Obligations of the Processor

The Processor undertakes to:

  • Process personal data only on documented instructions from the Controller;
  • Ensure that persons authorised to process data are bound by confidentiality obligations;
  • Implement the security measures set out in Art. 5 of this DPA;
  • Assist the Controller in fulfilling obligations relating to data subjects' rights;
  • Notify the Controller, without undue delay, of any personal data breach of which it becomes aware;
  • Delete or return data upon termination of the contract, in accordance with the Controller's instructions;
  • Make available to the Controller all information necessary to demonstrate compliance with GDPR obligations.

Art. 5 — Security Measures

The Processor has implemented the following technical and organisational measures in the NutriCare software:

  • Localhost-only network binding: the web server is bound to 127.0.0.1 and is not accessible from the network;
  • Administration console disabled: the H2 web console is deactivated in production builds;
  • API key encryption: AI provider API keys are encrypted at rest using AES-256-GCM;
  • Isolated JVM runtime: the Java runtime is bundled with the installer and not shared with other applications;
  • Per-OS-user data isolation: each Windows account accesses only its own data (NTFS permissions);
  • Development configuration excluded: development configuration files are not included in the distributed package.

The Controller remains responsible for the security of the infrastructure on which NutriCare is installed (disk encryption, OS password policies, backups).

Art. 6 — Sub-processors (AI Providers)

NutriCare optionally integrates third-party artificial intelligence services (OpenAI, Anthropic, Google) for AI-assisted dietary plan generation. Use of these services is optional and requires API keys supplied directly by the Controller.

When the Controller uses the AI generation feature, the Controller acts as Data Controller with respect to the chosen AI provider and is responsible for entering into its own DPA with that provider. Links to the main providers' DPAs:

  • OpenAI: platform.openai.com/docs/guides/privacy
  • Anthropic: www.anthropic.com/legal/privacy
  • Google (Gemini): ai.google.dev/gemini-api/terms

The Processor undertakes to inform the Controller of any changes to the list of sub-processors integrated in the software with at least 30 days' notice.

Art. 7 — International Data Transfers

Data stored by NutriCare remains on the Controller's device (EU territory, unless the device is located elsewhere). The Processor does not transfer patient data to third countries.

Optional use of AI providers based outside the EU (OpenAI: USA, Anthropic: USA, Google: USA) constitutes a transfer to third countries under the Controller's responsibility. The Controller must verify adequate safeguards under Arts. 44–49 GDPR (e.g. Standard Contractual Clauses) with each provider.

Art. 8 — Data Subjects' Rights

The Controller is responsible for handling requests to exercise data subjects' rights (access, rectification, erasure, portability, restriction, objection). The Processor shall assist the Controller upon request by providing technical documentation on how to extract or delete data from the local database.

Erasure: patient data can be deleted from the NutriCare interface. A full uninstall with removal of the %USERPROFILE%\.nutricare\ folder permanently deletes all data.

Art. 9 — Personal Data Breaches

In the event that the Processor becomes aware of a personal data breach directly affecting it (e.g. compromise of the distributed software package), it shall notify the Controller within 72 hours of becoming aware, providing available information pursuant to Art. 33 GDPR.

The Controller remains responsible for notification to the supervisory authority and, where applicable, to data subjects, pursuant to Arts. 33–34 GDPR.

Art. 10 — Data Deletion and Return

Upon termination of the licence agreement, the Controller retains possession of the local database (%USERPROFILE%\.nutricare\data\) and may export or delete it independently. The Processor holds no copies of the data and therefore has no return obligations.

Art. 11 — Governing Law and Jurisdiction

This DPA is governed by Italian law. Any dispute arising out of or in connection with the interpretation or performance of this Agreement shall be subject to the exclusive jurisdiction of the Court of [CITY], unless the parties agree otherwise in writing.
